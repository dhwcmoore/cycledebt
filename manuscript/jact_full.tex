\begin{abstract}
We present a finite cohomological obstruction classifier with machine-readable
JSON certificates for seam residues in finite regional covers. The classifier
tests cocycle and coboundary status over $\mathbb{Q}$, distinguishes direct
obstruction persistence from witness persistence, and decides cycle-faithfulness
with exact rational rank criteria. We prove the correctness of these tests and
document the results with audit-grade certificates and reproducible inputs.
\end{abstract}

\section{Introduction}
We study finite regional cohomology obstructions arising from seam residues in
oriented nerves. The main contributions are:
\begin{itemize}
  \item A classifier that decides whether a residue is a cocycle and whether it
    is a coboundary. The implementation produces machine-readable JSON
    certificates that encode cohomology summaries, cycle witnesses, and audit
    data.
  \item A separation of persistence notions under refinement: direct persistence
    versus witness persistence. We give algebraic criteria that distinguish them.
  \item Exact rational rank tests for cycle-faithfulness. When faithfulness
    fails, the implementation outputs a short rational witness.
\end{itemize}

The repository contains the code, the JSON inputs, the certificates, and the
scripts needed to reproduce all experiments.

\section{Background and notation}
Let $N$ be a finite oriented nerve with regions $U_i$. We work over $\mathbb{Q}$.
Denote cochain groups by $C^k(N;\mathbb{Q})$ with coboundary operators
$\delta^k:C^k\to C^{k+1}$. For a residue $r\in C^1$, we test the cocycle
condition $\delta^1 r = 0$ and whether $r$ lies in the image of $\delta^0$.
The cohomology group is $H^1 = \ker\delta^1/\operatorname{im}\delta^0$.

\section{Classification algorithm}
The classifier proceeds in two steps:
\begin{enumerate}
  \item Cocycle test: verify $\delta^1 r = 0$ (trivial when $C^2=0$).
  \item Coboundary test: solve the rational linear system $\delta^0 b = r$.
    If no solution exists, the residue represents a nonzero $H^1$ class.
\end{enumerate}

Implementation details: we use exact rational arithmetic \cite{sympy} to avoid
floating point error. The classifier emits a JSON certificate with fields
including \texttt{cohomology\_summary}, \texttt{cycle\_witness} (if available), and an audit trail.

\section{Invariance under presentation}
We prove the classification is invariant under five tested presentation changes:
region renaming, edge orientation reversal, nonzero rational scaling, gauge
perturbation $r\mapsto r+\delta^0 b$, and edge order permutation. Each
transformation preserves cohomology class. The implementation checks these
transformations and records stability in the invariance report.

\section{Refinements and transfer maps}
We consider refinements $\rho: N'\to N$ with transfer maps $\rho^*:C^1(N)\to C^1(N')$.
Our primary transfer strategy is equal‑distribution: split an old edge value
equally across the refined edges replacing it; internal refined edges receive 0.

Two persistence notions:
\begin{description}
\item[Direct persistence:] There exists $z'\in Z_1(N')$ with $\langle z',\rho^* r\rangle\ne0$.
\item[Witness persistence (cycle‑faithfulness):] There exists $z'\in Z_1(N')$ and
  $\lambda\in\mathbb{Q}^\times$ with $\rho_* z' = \lambda z$ for an original
  cycle $z$ pairing nontrivially with $r$.
\end{description}

We prove the Cycle‑Lift Persistence Theorem: if $\rho_* z' = \lambda z$ then
$[\rho^* r]\ne0$ whenever $\langle z,r\rangle\ne0$, by adjointness of $\rho^*$ and $\rho_*$.

\section{Cycle‑faithfulness and rational rank tests}
Cycle‑faithfulness can be decided by two algebraic methods:
\begin{itemize}
\item Nullspace method: solve a linear system for $(z',\lambda)$ certifying a nonzero lift.
\item Rank criterion: let $K$ be a basis for $Z_1(N')$ and $P=\rho_*$. Then $\rho$ is
  cycle‑faithful iff $\operatorname{rank}(PK)=\operatorname{rank}([PK\; z])$.
\end{itemize}

When $\operatorname{rank}(PK)=1$, faithfulness reduces to checking uniformity
of ratios $v_e/z_e$ for a generator $v$ of $\operatorname{im}(PK)$.
Failure is certified by a non‑uniform ratio vector (a short, exact rational witness).

\section{Discussion}
Direct persistence is strictly weaker than witness persistence. Equal-distribution
transfers can preserve a nonzero cohomology class. The original cycle may
nevertheless fail to lift proportionally. The rank test and failure witnesses
give exact, checkable certificates for both outcomes.
